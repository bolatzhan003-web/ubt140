## 🚀 Платформаны іске қосу (Запуск)

Сервер қазір қосулы тұр:
👉 **[http://localhost:3001](http://localhost:3001)**

Қайта іске қосу үшін:

  ```bash

  ```

## 🌟 Жүйедегі жаңа мүмкіндіктер мен өзгерістер

### 1. 🐆 UBT140.KZ Бренді және Маскот (Барсик)
- Басты бетте және карточкаларда арнайы салынған маскот — **Барсик** (Қар барысы, академиялық бас киімдегі 140 балл медалімен).
- Маскот оқушыларды ынталандыратын кеңестер береді.
- Дизайн қазақстандық стильде, ашық көгілдір және алтын түстермен безендірілген.

### 2. 🌐 Екі тілді қолдау (Қазақша 🇰🇿 / Орысша 🇷🇺)
- Жоғарғы мәзірдегі **QAZ / РУС** түймесі арқылы бүкіл сайт тілін (мәзір, батырмалар, сипаттамалар, сүзгілер) лезде ауыстыру.

### 3. 📚 Нақты ҰБТ пәндері бойынша құрылым
- Артық «деңгейлер» алынып тасталды, барлық курстар ҰБТ пәндеріне бағытталған:
  - *Математикалық сауаттылық*
  - *Қазақстан тарихы*
  - *Оқу сауаттылығы*
  - *Математика (бейіндік)*
  - *Физика*
  - *Химия*
  - *Биология*
  - *География*
  - *Ағылшын тілі*, т.б.

### 4. 📑 Мұғалімдер мен Әкімші үшін материалдарды жүктеу
- Әр бейнесабақтың астында мұғалімдер мен әкімшілер үшін **«Материал жүктеу (PDF, конспект, құжат)»** арнайы формасы қосылды.
- Оқушылар бекітілген формулалар шпаргалкасын және конспектілерді 1 батырмамен тегін жүктеп ала алады.
- Админкадағы курс конструкторында да әр сабаққа тікелей файл бекіту батырмасы бар.

### 5. 🎬 YouTube арқылы бейнедәрістер
- Барлық видеосабақтар YouTube сілтемесі арқылы сапалы түрде ойнатылады.
